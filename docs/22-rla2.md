# RLA-2: 极简硬截断线性注意力（修正版）

**版本**：2.1  
**日期**：2026-09-04  
**核心哲学**：无门控、无学习衰减、仅依赖 ReLU 硬截断和 RoPE 位置信息，实现全局动态稀疏检索。

---

## 1. 摘要

RLA-2 是对原始 RLA（ReLU-Linear Attention）的深度优化版本。它在保留原版 **O(Ld²)** 训练复杂度和 **O(d²) 每 token 推理复杂度** 的基础上，通过三项关键改进，解决了原版在数值稳定性、位置感知和神经元死亡方面的核心缺陷：

1. **归一化分母从 L2 改为 Sum** → 输出量级恒定，长度发散问题根治。
2. **移除强制指数衰减（γ）** → 完全依赖 RoPE 提供的位置信息，消除超参数，增强硬检索能力。
3. **RMSNorm 替代残差 Shortcut** → 保持 ReLU 硬截断纯粹性，稳定训练，降低神经元死亡。

最终算法极为简洁：**投影 → RMSNorm → RoPE → ReLU → 加权平均（Sum归一化）**。它本质上是一个 **带位置感知的核方法**，可解释性强，在超长上下文（>100K）任务中效率优势显著。

**本修正版重点解决以下一致性问题**：
- 统一推理与训练中的注意力分数定义（逐维 ReLU 后点积，而非对点积结果 ReLU）。
- 补充因果训练的正确实现方式（分块状态传递）。
- 修正对 RoPE 远程衰减和 RMSNorm 性质的表述。

## 2. 算法数学定义

### 2.1 注意力分数

对任意查询位置 \(t\) 与历史位置 \(i\)，首先计算：

\[
q_t' = \operatorname{ReLU}\left(\operatorname{RoPE}\left(\operatorname{RMSNorm}(W_q x_t)\right)\right)
\]

\[
k_i' = \operatorname{ReLU}\left(\operatorname{RoPE}\left(\operatorname{RMSNorm}(W_k x_i)\right)\right)
\]

\[
v_i = W_v x_i
\]

注意力分数定义为 **逐维 ReLU 后向量的点积**：

\[
s_{ti} = q_t' \cdot k_i' = \sum_{j=1}^{d} q_{t,j}' \, k_{i,j}'
\]

> **注意**：不要写成 \(\operatorname{ReLU}(q_t \cdot k_i)\)，这两种形式不等价。只有逐维 ReLU 后才能利用矩阵结合律实现线性复杂度。

### 2.2 因果推理（逐 token 增量形式）

维护两个固定大小的状态：

\[
S_t = \sum_{i=1}^{t} k_i' \otimes v_i \quad \in \mathbb{R}^{d \times d}
\]

\[
z_t = \sum_{i=1}^{t} k_i' \quad \in \mathbb{R}^{d}
\]

当前输出为：

\[
\text{Output}_t = \frac{q_t' \, S_t}{q_t' \cdot z_t + \epsilon}
\]

其中 \(\epsilon\) 为小常数（如 \(1e-4\)）防止除零。状态更新规则：

\[
S_t = S_{t-1} + k_t' \otimes v_t
\]

\[
z_t = z_{t-1} + k_t'
\]

**每 token 推理复杂度为 \(O(d^2)\)，与序列长度无关**。初始状态 \(S_0 = 0,\; z_0 = 0\)。

### 2.3 因果训练（分块并行形式）

训练时不能直接使用非因果的全矩阵形式 \(Q' K'^T V\)，因为会泄露未来信息。必须采用 **分块因果线性注意力**。基本思想：

- 将长度为 \(L\) 的序列划分为 \(B\) 个块，每块大小 \(C\)（通常 64~256）。
- 对于每个块 \(b\)，维护来自之前所有块的累积状态 \(S_{\text{prev}}^{(b)}\) 和 \(z_{\text{prev}}^{(b)}\)。
- 块内计算使用标准线性注意力，但只作用于当前块；同时将当前块的键值对累加入状态，传递给下一块。

伪代码示意：

```python
def causal_linear_attention(Q, K, V, chunk_size):
    # Q, K, V: (B, L, d)，已经过 ReLU 和 RoPE
    B, L, d = Q.shape
    S = torch.zeros(B, d, d, device=Q.device)
    z = torch.zeros(B, d, device=Q.device)
    outputs = []
    for i in range(0, L, chunk_size):
        Q_c = Q[:, i:i+chunk_size]      # (B, C, d)
        K_c = K[:, i:i+chunk_size]
        V_c = V[:, i:i+chunk_size]

        # 当前块内部注意力（因果，但块内仍可并行）
        # 分子：Q_c (K_c^T V_c) ，分母：Q_c (K_c^T 1)
        num_inner = torch.matmul(Q_c, torch.matmul(K_c.transpose(-2,-1), V_c))
        den_inner = torch.matmul(Q_c, K_c.sum(dim=1, keepdim=True))  # (B,C,1)

        # 与历史状态的交互
        num_hist = torch.matmul(Q_c, S)      # (B,C,d)
        den_hist = torch.matmul(Q_c, z.unsqueeze(-1))  # (B,C,1)

        output = (num_inner + num_hist) / (den_inner + den_hist + eps)
        outputs.append(output)

        # 更新状态
        S = S + torch.matmul(K_c.transpose(-2,-1), V_c)
        z = z + K_c.sum(dim=1)

    return torch.cat(outputs, dim=1)
```

该实现的复杂度为 \(O(L d^2)\)，空间复杂度 \(O(L d + B d^2)\)。块内计算虽仍为线性注意力，但由于块大小有限，可以高效并行。

## 3. 与原版 RLA 的关键差异

| 特性 | 原版 RLA | RLA‑2 |
| :--- | :--- | :--- |
| 归一化分母 | \(\sqrt{\sum \text{score}^2} + \epsilon\) | \(\sum \text{score} + \epsilon\) |
| 分数定义 | 不一致（推理为 ReLU(点积)，训练为 ReLU(向量)点积） | **统一为逐维 ReLU 后点积** |
| 位置编码 | 必须 RoPE | 同左（严格强制） |
| 距离衰减 | 可加 γ^(t-i)（但未强制） | **无**（仅依靠 RoPE 提供的位置信息） |
| 防神经元死亡 | 残差 shortcut `ReLU(x)+0.1*x` | RMSNorm（前置） |
| 额外超参数 | γ（若使用） | **零** |
| 硬截断纯粹性 | 被残差泄漏破坏 | **完全保留**（负数精确归零） |
| 输出量级 | 随 √L 增长 | **恒定**（加权平均） |
| 推理复杂度 | 每 token O(t d)（若直接求和） | **每 token O(d²)**（状态递推） |

## 4. 设计哲学与理论优势

### 4.1 为何抛弃 L2 归一化？

- L2 归一化等效于对注意力分数做余弦相似度约束，但会导致输出幅度随序列长度 \(L\) 增长（因为分母为 \(\sqrt{\sum \text{score}^2}\)）。在长上下文中数值容易越界。
- Sum 归一化使输出变为 V 的**加权平均**，幅值完全稳定，且梯度流更平滑。

### 4.2 为何无需强制衰减？

- 在原始 softmax 注意力中，RoPE 通过内积的相位差自然产生远程衰减。但在本模型中，由于先对 RoPE 输出做了逐维 ReLU，点积不再等于旋转前的内积，因此 **不保证严格的单调远程衰减**。
- 然而，RoPE 仍然为不同位置提供不同的旋转角度，使得语义相近的 q、k 可能因位置差异导致部分维度符号翻转，从而改变 ReLU 激活模式，间接影响点积大小。这种机制使模型能够学习到 **位置相关的稀疏性**，但缺乏理论上的远程衰减保证。
- 强制 γ 衰减会**弱化硬检索能力**：若关键信息在开头，过远的距离会使其分数被压到接近零，可能被 ReLU 截断。移除 γ 后，模型仅依赖语义和旋转位置编码来决定稀疏权重，更符合“语义优先”原则。
- 实际实验中，RoPE+ReLU 仍能有效区分远近，但若需要严格的距离衰减，可考虑在分数上加一个小的可学习偏差（但会增加超参数）。

### 4.3 为何用 RMSNorm 而非残差 Shortcut？

- 残差 `ReLU(x)+0.1*x` 引入了**负值泄漏**，违背 ReLU 的“负数彻底屏蔽”语义。
- RMSNorm 在 ReLU **之前** 将 Q/K 向量的均方根归一化到 1，**稳定数值分布，减少梯度消失/爆炸**，大幅降低死亡神经元比例，同时保持硬截断的纯粹性。
- RMSNorm **默认不引入可学习参数**（仅归一化缩放，可设置固定增益），符合极简原则。若后续需要增强多头多样性，可考虑为每头增加独立的可学习增益（见第 7 节）。

### 4.4 可解释性

- 每个历史 token 的权重为 \(s_{ti} = q_t' \cdot k_i'\)，它是两个非负向量的点积。仅当对应维度同时为正值时才对分数有贡献。
- 权重大小直接反映**逐维语义对齐程度**，且不经过 softmax 的指数挤压，保持线性可解释性。可以逐维度分析 q 和 k 的激活模式来解释注意力行为。

### 5.1 层定义

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class RMSNorm(nn.Module):
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.eps = eps
        # 无参数版本，固定增益为1
    def forward(self, x):
        rms = torch.sqrt(torch.mean(x**2, dim=-1, keepdim=True) + self.eps)
        return x / rms

class RLA2Attention(nn.Module):
    def __init__(self, dim, eps=1e-4):
        super().__init__()
        self.eps = eps
        self.w_q = nn.Linear(dim, dim, bias=False)
        self.w_k = nn.Linear(dim, dim, bias=False)
        self.w_v = nn.Linear(dim, dim, bias=False)
        self.w_o = nn.Linear(dim, dim, bias=False)
        self.rms_norm_q = RMSNorm(dim)
        self.rms_norm_k = RMSNorm(dim)

    def forward(self, x, rope_fn):
        # x: (B, L, d)
        q = self.rms_norm_q(self.w_q(x))
        k = self.rms_norm_k(self.w_k(x))
        v = self.w_v(x)

        q_rope = rope_fn(q)
        k_rope = rope_fn(k)

        q_prime = F.relu(q_rope)   # (B, L, d)
        k_prime = F.relu(k_rope)   # (B, L, d)

        # 注意：此处演示因果分块训练的前向，实际训练需按 2.3 节实现
        # 若为非因果（如双向编码器），可使用以下高效形式：
        # kv = k_prime.transpose(-2,-1) @ v          # (B,d,d)
        # num = q_prime @ kv                          # (B,L,d)
        # den = q_prime @ k_prime.sum(dim=1, keepdim=True).transpose(-2,-1) + self.eps  # (B,L,1)
        # out = num / den
        # return self.w_o(out)

        # 对于自回归训练，调用因果分块函数
        out = causal_linear_attention(q_prime, k_prime, v, chunk_size=128)
        return self.w_o(out)
```

### 5.2 推理逐 token 增量

```python
def rla2_step(q_t, state, k_t, v_t, eps=1e-4):
    """
    q_t: (1, 1, d) 已过 RMSNorm + RoPE + ReLU
    k_t: (1, 1, d) 已过 RMSNorm + RoPE + ReLU
    v_t: (1, 1, d) 原始 v
    state: (S, z)，其中 S: (1,d,d), z:(1,d)
    """
    S, z = state
    # 更新状态
    S = S + torch.matmul(k_t.transpose(-2,-1), v_t)  # (1,d,d)
    z = z + k_t.squeeze(1)                            # (1,d)

    # 计算输出
    num = torch.matmul(q_t, S)                        # (1,1,d)
    den = torch.matmul(q_t, z.unsqueeze(-1)) + eps    # (1,1,1)
    out = num / den
    return out, (S, z)
```

## 8. 训练实用建议

- **初始化**：Q/K 投影权重采用标准差 `0.02` 的正态分布，避免 ReLU 前数值过大。
- **混合精度**：推荐使用 AMP（FP16/BF16），RMSNorm 和 RoPE 对精度不敏感。
- **梯度裁剪**：全局范数裁剪至 `1.0` 可提升稳定性。
- **学习率**：典型值 `1e-3`（AdamW），配合余弦退火。
- **块大小**：训练时建议块大小 128~256，兼顾并行效率与内存。

# LRLA: 可学习 ReLU 线性注意力

**版本**：1.0  
**日期**：2026-09-04  
**核心哲学**：保留 ReLU 硬截断的稀疏与可解释性，通过引入可学习的多层特征映射提升表达能力，同时严格维持线性注意力的高效复杂度。

---

## 1. 摘要

LRLA（Learnable ReLU Linear Attention）是对 RLA‑2 的进一步扩展。在 RLA‑2 中，特征映射被固定为单层线性变换后接 ReLU，虽然简洁高效，但对复杂 token 间交互关系的建模能力有限。LRLA 将这一映射替换为**可学习的多层非线性网络**，在保留 ReLU 硬截断和非负分数特性的基础上，大幅增强模型容量，尤其适合需要复杂语义匹配的长序列任务。

核心改进：

- **可学习特征映射**：使用 MLP（或多层网络）替代单层线性 + ReLU，最后一层仍为 ReLU 以保证分数非负。
- **维持线性复杂度**：无论特征映射多复杂，只要输出为非负向量，训练复杂度仍为 \(O(L d_\phi d)\)，推理每步 \(O(d_\phi d)\)，与序列长度无关。
- **继承 RLA‑2 优点**：无 softmax、无门控、无额外位置衰减，仅依赖 RoPE 提供位置信息，保持硬截断和可解释性。
- **统一分数定义**：严格使用 \(\phi_q(q) \cdot \phi_k(k)\) 作为注意力分数，避免训练/推理不一致。

LRLA 可视为一种**可学习核的线性注意力**，在超长上下文、硬检索与复杂推理任务之间取得更优平衡。

---

## 2. 算法数学定义

### 2.1 特征映射

定义两个可学习的非线性映射 \(\phi_q, \phi_k: \mathbb{R}^{d} \rightarrow \mathbb{R}^{d_\phi}\)（通常 \(d_\phi = d\)，也可扩展）。它们均由多层前馈网络构成，最后一层使用 ReLU 激活以保证输出非负：

\[
\phi(x) = \operatorname{ReLU}\left( W_L \cdot \sigma_{L-1}( W_{L-1} \cdot \cdots \sigma_1(W_1 x) ) \right)
\]

其中 \(\sigma_i\) 可为 GELU、SiLU 等平滑激活，最后一层必须为 ReLU（或 Softplus 等非负激活）。可选残差连接、归一化层增强稳定性。

### 2.2 注意力分数

对查询位置 \(t\) 与历史位置 \(i\)，先计算：

\[
q_t^\phi = \phi_q\left( \operatorname{RoPE}(W_q x_t) \right)
\]

\[
k_i^\phi = \phi_k\left( \operatorname{RoPE}(W_k x_i) \right)
\]

\[
v_i = W_v x_i
\]

注意力分数定义为 **特征向量点积**（均为非负向量）：

\[
s_{ti} = q_t^\phi \cdot k_i^\phi = \sum_{j=1}^{d_\phi} q_{t,j}^\phi \, k_{i,j}^\phi \;\; \geq 0
\]

> **关键**：这里是对映射后的向量逐元素乘积再求和，而不是对原始点积做 ReLU。只有这样才能保证线性复杂度下的矩阵结合律。

### 2.3 因果推理（增量形式）

维护两个固定大小的状态：

\[
S_t = \sum_{i=1}^{t} k_i^\phi \otimes v_i \in \mathbb{R}^{d_\phi \times d}
\]

\[
z_t = \sum_{i=1}^{t} k_i^\phi \in \mathbb{R}^{d_\phi}
\]

输出为：

\[
\text{Output}_t = \frac{q_t^\phi \, S_t}{q_t^\phi \cdot z_t + \epsilon}
\]

其中 \(\epsilon\) 为小常数（如 \(1e-4\)）。状态更新：

\[
S_t = S_{t-1} + k_t^\phi \otimes v_t
\]

\[
z_t = z_{t-1} + k_t^\phi
\]

每 token 计算复杂度为 \(O(d_\phi d)\)，与序列长度无关。

### 2.4 因果训练（分块并行）

由于自回归特性，训练时需使用分块因果线性注意力，避免未来信息泄露。定义块大小 \(C\)，对序列分块后，块内并行计算，块间通过状态传递实现因果。

对每个块 \(b\)（包含位置 \(i = bC, \dots, (b+1)C-1\)）：

1. 计算块内注意力输出（使用块内 \(K_\text{local}, V_\text{local}\)）  
2. 计算与历史状态的交互（使用累积状态 \(S_{\text{prev}}, z_{\text{prev}}\)）  
3. 合并输出  
4. 更新全局状态，传递至下一块

具体公式：

\[
O_{\text{inner}} = \frac{Q_\text{chunk} \, (K_\text{chunk}^T V_\text{chunk})}{Q_\text{chunk} \, (K_\text{chunk}^T \mathbf{1}) + \epsilon}
\]

\[
O_{\text{hist}} = \frac{Q_\text{chunk} \, S_{\text{prev}}}{Q_\text{chunk} \, z_{\text{prev}} + \epsilon}
\]

\[
O_{\text{chunk}} = \frac{Q_\text{chunk} \, (K_\text{chunk}^T V_\text{chunk} + S_{\text{prev}})}{Q_\text{chunk} \, (K_\text{chunk}^T \mathbf{1} + z_{\text{prev}}) + \epsilon}
\]

状态更新：

\[
S_{\text{next}} = S_{\text{prev}} + K_\text{chunk}^T V_\text{chunk}
\]

\[
z_{\text{next}} = z_{\text{prev}} + K_\text{chunk}^T \mathbf{1}
\]

## 3. 复杂度分析

设特征维度 \(d_\phi\)，序列长度 \(L\)，块大小 \(C\)，模型维度 \(d\)。

- **训练**：  
  - 计算 \(\phi_q, \phi_k\) 的前向/反向：\(O(L d^2)\)（若 MLP 隐藏层维度为 d）  
  - 线性注意力核心：\(O(L d_\phi d)\)  
  - 总复杂度：\(O(L d (d + d_\phi))\)，通常 \(d_\phi = d\) 时为 \(O(L d^2)\)  
  - 空间复杂度：\(O(L d + B d_\phi d)\)，其中 \(B = L/C\) 为块数

- **推理（单步）**：  
  - 状态更新：\(O(d_\phi d)\)  
  - 输出计算：\(O(d_\phi d)\)  
  - 总复杂度：\(O(d_\phi d)\)，恒定，不随上下文长度增长

- **内存**：状态矩阵 \(S \in \mathbb{R}^{d_\phi \times d}\) 与 \(z \in \mathbb{R}^{d_\phi}\)，与序列长度无关。

## 4. 与 RLA‑2 的关键差异

| 特性 | RLA‑2 | LRLA |
| :--- | :--- | :--- |
| 特征映射 | \(\phi(x) = \operatorname{ReLU}(\operatorname{RoPE}(\operatorname{RMSNorm}(Wx)))\) | \(\phi(x) = \operatorname{ReLU}(\operatorname{MLP}(\operatorname{RoPE}(Wx)))\) |
| 可学习参数 | Q/K 投影 + RMSNorm 增益 | Q/K 投影 + MLP 权重（多一层或多层） |
| 非线性深度 | 单层 ReLU | 至少两层（如 GELU 中间层 + ReLU 输出） |
| 表达能力 | 有限，仅能建模线性可分模式 | 增强，可拟合复杂语义匹配 |
| 复杂度 | \(O(L d^2)\) 训练，\(O(d^2)\) 推理 | 同左（若 \(d_\phi = d\)，仅增加 MLP 计算常数） |
| 稀疏性 | 硬截断纯粹 | 同左，最后一层 ReLU 保持 |
| 可解释性 | 高，逐维可直接分析 | 略低，但最后一层仍为非负，可逐维分析 |

## 5. 设计哲学与理论优势

### 5.1 为何需要可学习映射？

RLA‑2 的单层线性 + ReLU 本质上是一个可学习的核函数，但表达能力受限于单层线性变换。例如，某些语义关系需要非线性组合（如“A 依赖 B 且 C 不依赖 D”）才能有效区分，单层可能无法捕捉。引入 MLP 后，模型可以学习更复杂的 token 间交互模式，同时保留非负性和稀疏性。

### 5.2 保持 ReLU 硬截断的理由

- **稀疏性**：大量零分数使注意力分布自然稀疏，符合人类认知中的选择性关注。
- **可解释性**：非负分数可逐维度分析哪个特征维度贡献了注意力。
- **计算友好**：非负性避免分母出现负数，数值更稳定。

虽然中间层可以使用 GELU 等平滑激活，但最后一层必须使用 ReLU（或 Softplus）来保证非负输出。

### 5.3 与标准 softmax 注意力的关系

标准 softmax 注意力使用指数核 \(\exp(q \cdot k / \sqrt{d})\)，理论上具有无限维特征映射。线性注意力用有限维特征映射近似，而 LRLA 通过可学习网络尽量逼近最优特征映射，可视为对 softmax 核的有参近似。

### 5.4 位置信息的处理

RoPE 必须施加在进入多层网络**之前**。因为多层非线性会破坏旋转相对位置性质，但 RoPE 的位置信息会作为输入特征的一部分被 MLP 进一步加工，使模型能够学习位置与语义的复杂交互。这不同于标准 RoPE 在 softmax 中的简单内积用法。

## 6. PyTorch 实现伪代码

### 6.1 特征映射模块

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class LearnableFeatureMap(nn.Module):
    def __init__(self, dim, hidden_dim=None, dropout=0.0):
        super().__init__()
        hidden_dim = hidden_dim or dim
        self.fc1 = nn.Linear(dim, hidden_dim, bias=False)
        self.fc2 = nn.Linear(hidden_dim, dim, bias=False)
        self.norm = nn.LayerNorm(dim)          # 输入归一化（可选）
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        # x: (B, L, dim)，已包含 RoPE 信息
        x = self.norm(x)
        h = F.gelu(self.fc1(x))
        h = self.dropout(h)
        out = self.fc2(h)
        return F.relu(out)   # 非负输出
```

### 6.2 LRLA 注意力层

```python
class LRLAAttention(nn.Module):
    def __init__(self, dim, eps=1e-4, dropout=0.0):
        super().__init__()
        self.eps = eps
        self.w_q = nn.Linear(dim, dim, bias=False)
        self.w_k = nn.Linear(dim, dim, bias=False)
        self.w_v = nn.Linear(dim, dim, bias=False)
        self.w_o = nn.Linear(dim, dim, bias=False)
        self.phi_q = LearnableFeatureMap(dim, dropout=dropout)
        self.phi_k = LearnableFeatureMap(dim, dropout=dropout)

    def forward(self, x, rope_fn):
        # x: (B, L, dim)
        q = self.w_q(x)
        k = self.w_k(x)
        v = self.w_v(x)

        q_rope = rope_fn(q)
        k_rope = rope_fn(k)

        q_phi = self.phi_q(q_rope)   # (B, L, dim)
        k_phi = self.phi_k(k_rope)   # (B, L, dim)

        # 注意：此处演示非因果形式；自回归训练需使用分块因果实现
        kv = torch.matmul(k_phi.transpose(-2, -1), v)           # (B, dim, dim)
        num = torch.matmul(q_phi, kv)                           # (B, L, dim)
        den = torch.matmul(q_phi, k_phi.sum(dim=1, keepdim=True).transpose(-2, -1)) + self.eps  # (B, L, 1)
        out = num / den
        return self.w_o(out)
```

### 6.3 推理增量

```python
def lrla_step(q_phi, state, k_phi, v_t, eps=1e-4):
    """
    q_phi: (1, 1, dim)  已通过 φ_q
    k_phi: (1, 1, dim)  已通过 φ_k
    v_t:   (1, 1, dim)
    state: (S, z) 其中 S: (1, dim, dim), z: (1, dim)
    """
    S, z = state
    # 更新状态
    S = S + torch.matmul(k_phi.transpose(-2, -1), v_t)
    z = z + k_phi.squeeze(1)

    num = torch.matmul(q_phi, S)                    # (1, 1, dim)
    den = torch.matmul(q_phi, z.unsqueeze(-1)) + eps
    out = num / den
    return out, (S, z)
```

## 7. 潜在问题与解决方案

| 问题 | 解决方案 |
| :--- | :--- |
| **参数增多导致过拟合** | 使用 dropout、权重衰减，或共享 Q/K 映射的底层参数 |
| **计算开销增加** | 保持隐藏层维度与模型维度相同，或使用低秩分解 MLP |
| **训练不稳定** | 在 MLP 内部加入 LayerNorm/RMSNorm，使用残差连接，适当降低学习率 |
| **ReLU 死亡神经元** | 中间层使用 GELU/SiLU，最后一层 ReLU；使用较小的初始化标准差 |
| **位置信息被 MLP 稀释** | 可添加残差连接 \( \phi(x) = \text{ReLU}(x + \text{MLP}(x)) \) 保留原始 RoPE 信息 |
| **特征维度 \(d_\phi\) 选择** | 通常与模型维度一致；若需更高容量，可设 \(d_\phi = 2d\)，但注意状态矩阵大小增加 |
| **分母过小** | 使用 eps 并可用 `torch.clamp(denominator, min=eps)` |

## 8. 训练实用建议

- **初始化**：Q/K/V 投影使用标准差 `0.02` 的正态分布；MLP 权重使用 Xavier/He 初始化。
- **优化器**：AdamW，学习率 `1e-3` 或稍低（因参数更多），配合线性预热和余弦退火。
- **混合精度**：推荐 BF16/FP16，注意 LayerNorm 和 MLP 的数值稳定性。
- **块大小**：训练因果分块时，块大小可设为 128~256，平衡并行度与内存。
- **正则化**：对 MLP 使用 dropout（如 0.1），权重衰减 `1e-4`。
- **监控指标**：观察 ReLU 输出的稀疏比例，若超过 90% 为零，可尝试降低学习率或调整初始化。

## 10. 未来扩展方向

- **深度可分离特征映射**：将 MLP 分解为低秩矩阵，降低参数和计算量。
- **多尺度特征映射**：在不同层使用不同深度或宽度的 φ，实现层次化表示。
- **混合核**：将 ReLU 特征映射与其他非负核（如 Softplus、随机特征）组合，提升容量。
- **门控机制**：在保持线性复杂度的前提下，引入轻量门控调整状态更新强度（如 Gated Linear Attention 的变体）。
- **动态 \(d_\phi\)**：根据输入序列长度或任务难度动态调整特征维度，平衡成本与性能。
- **与稀疏注意力结合**：局部窗口用标准 softmax 注意力，全局用 LRLA，兼顾局部精细建模与长程高效检索。

## 11. 结论

LRLA 通过引入可学习的多层特征映射，突破了 RLA‑2 单层 ReLU 的表达瓶颈，同时完整继承了线性注意力的复杂度优势和硬截断带来的稀疏性、可解释性。它是一个灵活且高效的框架，可根据任务需求调整映射深度和宽度，在长上下文建模、硬检索和中等复杂度推理任务中展现出强大的竞争力。对于希望在保持线性复杂度同时提升模型容量的研究者和工程师，LRLA 提供了一个极具潜力的基础架构。
