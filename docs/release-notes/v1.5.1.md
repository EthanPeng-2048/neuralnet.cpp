## 1. ZiPT（AttnZip）移出主线

**裁决依据（代码事实，非文档声明）**：① 缺省 `window=0` → `W = L` → `split_ = false`，块内仍是
`W = L` 的联合注意力（O(L²)），还额外物化并缓存一张 `BH·W·(M+W)` 的 F32 掩码；② 压缩器只有
模型级一份且作用在嵌入上；③ **压缩非因果**（压缩整条含未来 token 的序列）；④ 无
`forward_recompute` / activation offload；⑤ 全仓零质量/成本数据；⑥ CLI 自 2026-09-29 起
abort 且无人发现。

**恢复前提（两条同时满足才可重新立项）**：算法层压缩向量必须**因果**；代码层实现质量对齐
RAPT/GPT（梯度检查点 + offload + CLI/序列化/测试齐备）**且有同参同预算对比数据**。

**删除面**：`compute_layer_zipt.hpp` / `domain_zipt.hpp` / 5 个 `zipt_*.cpp` / 07 号文档；
符号 `CrossAttention` / `ZiPTBlock` / `ZiPTModel` / `build_zipt_model*` / `make_zipt_spec` /
`ZiPTConfig` / `ZIPT_MEMORY_TOKENS` / `ModelSpec::is_zipt` / `concat_cols`；
CLI `--model zipt` / `--window` / `--memory-tokens`。

**兼容性**：`ModelType` 的 6 号保留为 `Reserved_ZiPT` **占位**，`spec_from_kv` 对旧 `type=6` 的
`.bin` 给出明确错误（新增测试锁定）；需要 ZiPT 的调用方走 `legacy/zipt` 分支。

## 2. GUI / CLI 参数一致性清理

- **多余项**：CUDA 残留（`gui.py` 的 `ENGINE_OPTIONS` 仍列 `"CUDA"`、4 处 `args["cuda"]` 分支、
  两个 `build_pack_config` 的 `device: "cuda"`、`train_pkg.py --device cuda`）——CUDA 后端早已移除，
  选中它实际按 CPU 静默跑且无提示；本轮全删，`train_pkg.py --device` 只留 `cpu/gpu`（旧包 `cuda`
  字段改为**显式忽略**）。ZiPT 残留（`model_type` 列表、`memory_tokens`/`window` 控件与显隐回调、
  `cli_controllers` 的两个映射）同批删除。
- **幽灵选项**：`mnist_train --osc-guard/--osc-window/--osc-threshold`（帮助声明了、无解析分支，
  传入即"未知参数"退出）—— 帮助 + 控制器映射 + GUI 三层一起删（不补实现）。
- **缺失项**：`mnist_train --shuffle-steps/--lr-per-epoch`；`text_train --resume-epoch/--resume-step/
  --no-cache/--lr-per-epoch`；`tokenizer_train --threads`；`tokenizer_infer --top/--threads` +
  "统计每行 token 数"位置参数模式；`text_infer --vocab`。有意不暴露：两个 infer 的 `--interactive`
  （GUI 本身即交互外壳）。
- **顺带修复**：`cli_controllers` 对 `--shuffle-steps` 传 bool → `_format_arg_value` 渲染为空串 →
  必然触发"无效 `--shuffle-steps`"；现对 bool 显式转 `true/false`。

## 3. 迁移指南

| 旧用法 | 现状 | 迁移 |
|---|---|---|
| `text_train --model zipt` / `--window` / `--memory-tokens` | 参数已删除，传入即"未知参数"退出 | 用 `--model rapt` 或默认 GPT；需要 ZiPT 走 `legacy/zipt` 分支 |
| GUI 训练页引擎下拉的 CUDA | 选项删除 | 选 `CPU` / `Vulkan` |
| `.nnpkg` 包里的 `device: "cuda"` | 显式忽略（不再报错） | 重新打包即写 `cpu`/`gpu` |
| `mnist_train --osc-*` | 参数删除 | 无对应功能（自适应启发式已整体移除） |
| 依赖旧 GUI 默认值（MNIST transformer/32 批、GPT 1000 级 d_ff 等） | 默认值与 CLI 对齐（见 §0 表） | 需要旧值请在页面上显式填写 |
