# neuralnet.cpp v1.8.0 Release Notes

> **发布范围**：`v1.7.1`（`cf430d0`，2026-10-05）→ `v1.8.0`（`afcb3d0`，2026-10-11）。
> **主题**：**三值权重（T1_58）全链路** + **模型文件 v7 与角色语义** + **引擎能力内敛** + **三值性能优化** + **`AdamWQuant`** + **探针统一编译门**。
> **兼容性**：**有破坏性变更**——模型文件升 **v7**（v5/v6/v7 可读）、移除 `supports_*` 能力谓词 / `Layer::sub_layers()` / NNQT 独立部署格式与 `--export-deploy`；迁移见 §6。ctest **27 → 37**（GPU 树；无 Vulkan 树按 77 跳过 GPU 用例）。

## 0. 亮点速览（TL;DR）

| 方向 | 变化 | 收益 |
|---|---|---|
| 三值精度 | `Precision::T1_58`：按逐行 absmean 尺度把权重投影到 `{-1,0,+1}`，配 STE 反向；`BitLinear` + `--t1_58` 预设 | 模型参数可压到 1.58-bit；MLP 与 GPT 全链路接线，RAPT/ViT 明确拒绝 |
| 打包 GEMM | `trit_pack` / `matmul_q` / `matmul_q_t`：2 bit/权重、4 权重/字节；CPU 行块解码 + GPU 分块/GEMV 两条 pipeline | 训练与解码共用打包形态；小 N 走专用 GEMV，避免稠密回退 |
| 量化缓存 | Tensor 存储对象持 `write_epoch`，所有写入口推进；`BitLinear` 仅在 epoch 变化时重量化 | 覆盖梯度累积 / 逐 token 生成 / 激活重计算三种重复调用，不会静默用旧权重 |
| 显存 | `BitLinear` 梯度惰性分配；`AdamWQuant` 优化器状态 f16 + 逐行有界尺度 | 推理不再为梯度付显存；优化器状态 **4 B/权重 vs 8 B**，实测峰值 **−16.2%** |
| 模型文件 v7 | 单一格式、两种角色：`.nnmodel` 推理（三值层写打包 + τ，盘上 base-3 **1.6 bpw**）/ `.nnckpt` 训练断点（f32 latent）；参数级 `kind` 条目 | 推理文件显著变小；同一读写器覆盖训练/部署，删除 NNQT 独立格式 |
| 引擎能力 | `describe()` 的 `EngineInfo` 成为唯一对外能力通道；`supports_*` 谓词私有化 | 能力事实只在一处披露，新增后端不必维护基类谓词 |
| 探针 | `NN_ENABLE_PROBES` 统一编译门（默认 OFF） | 默认构建零探针分支/字符串/getenv；排障时一次配置全部打开 |
| 可移植性 | MSVC 必须 `/Zc:preprocessor`；libc++ 死变量清理 | 变参宏在 cl.exe 传统预处理器下不再静默退化；四种「编译器 × 标准库」组合可构建 |

## 1. 三值权重（T1_58）

- `Precision::T1_58` 是**离散化**而非舍入：逐行 `τ = mean(|W|)`，权重投影到 `{-1,0,+1}`，另存尺度 `τ`；它**不进提升序**（`precision_rank()` 无定义），只作为 `PrecisionProfile.param` 与层能力集合的取值。
- `BitLinear`：量化 forward + STE backward，latent 恒 f32；`param={T1_58}`，其余槽沿用 f16/f32。`Layer::init` 按槽校验能力，不兼容组合初始化期报错。
- 预设：`profile_t1_58()` = `{param=T1_58, compute=F16, stable=F32, optimizer=F32}`；CLI `--t1_58`、GUI 两个训练页的精度预设同步。
- 接线范围：P1 = MLP；P1.5 = GPT 的 4 个投影 / `fc1_` / `fc2_` / 未 tie 的 `lm_head_` 全部经 `make_linear_layer`；RAPT / ViT 前置拒绝并给出明确错误。

## 2. 三值性能优化

- **写版本（write epoch）**：`MatrixT` / `GpuBuffer` 持单调 `write_epoch`；`ComputeEngine` 每个写入口首行 `WriteEpochGuard`（成功/失败都 +1）；CPU DSL 直写路径经 `TensorAccess::mark_written` 补记。`src/write_epoch_test.cpp` 逐入口断言。
- **打包原语**：布局 = 2 bit/权重 + 4 权重/字节 + 码值 = 三值 + 2（与 microsoft/BitNet 的 `pack_weight.py` 一致）；容器是 f32 张量当原始字，编解码唯一来源 `ternary_pack.hpp`。
- **CPU**：`matmul_q_impl` 行块解码（RB=64）+ 稠密微内核；禁止逐元素直算回退。
- **GPU**：`matmul_q.comp` 分块（BM=BN=64，x↔输出列 N / y↔输出行 M）；`N ≤ 8 且 transA=0` 走 `matmul_q_gemv.comp`（subgroup=4 行，subgroup 内沿打包字分片）。
- **实测**：850M / 40HX 的配对 A/B 与端到端口径见 [`../todo/21-quantized-weights.md`](../todo/21-quantized-weights.md) §4.12–§4.14；`layer_bench --op matmul,matmul_q,matmul_q_bw --f16` 可复现。

## 3. 模型文件 v7 与角色语义

- **文件头**：`magic | version=7 | 精度 | role 1B | spec`；参数区改为参数级 `kind` 条目（`[kind][precision][rows][cols][aux_len][payload_len][aux][payload]`），由拥有该参数的层经 `Layer::export_param` / `import_param` 决定形态。
- **角色**：`.nnmodel` = 推理（三值层写打包形态，盘上 base-3 1.6 bpw + τ）；`.nnckpt` = 训练断点（写 f32 latent）。`--save` 默认写 `.nnmodel`，`--save-interval` 写 `.nnckpt`，`--resume` 只认 `.nnckpt`。
- **读兼容**：v5 / v6 / v7 均可读；v5 及以下按版本分派内嵌 JSON 词表。
- **删除**：NNQT 独立格式（`ternary_deploy.hpp` / `ternary_deploy_test.cpp`）、`--export-deploy` 及 GUI/控制器/推理 CLI 的部署文件分流。

## 4. `AdamWQuant`

- 量化状态的 AdamW：一阶/二阶矩存 f16，配**逐行有界尺度**，状态 **4 B/权重**（Adam/AdamW 为 8 B）。
- 更新公式按尺度换算，数学语义不变；逐行尺度保证 f16 动态范围。
- 实测同任务 GPU 训练峰值显存 **−16.2%**；`adam_quant_test`（含 GPU 变体）覆盖状态往返与更新一致性。

## 5. 引擎能力、探针与可移植性

- **能力内敛**：`EngineInfo` 经 `describe()` 唯一披露（`virtual methods` 保持 52）；基类 `supports_native_data_move` / `supports_native_f16_reduce` / `supports_expr_precision_variant` / `supports_ternary_gemm` / `supports_int8_dot` / `int8_dot_accelerated` 删除，引擎侧落成私有事实 + `*_impl` 分支。`Layer::sub_layers()` 删除，参数下标转发改走受保护的 `param_children()`。
- **探针门**：`NN_ENABLE_PROBES`（默认 OFF）统一门控热路径采样/打印/下载/扫描；库内 `nn_dbg_scan`、`NN_PREC_TRACE`、`env_flag`、`text_train` 的 `NN_NAN_TRACE` / `NN_MEM_STATS` 与探针可执行目标全部走该门。门关时连 `getenv` 都不求值。
- **MSVC**：`/Zc:preprocessor` 写入目录级与接口选项——传统预处理器会把 `NN_UNWRAP(x, msg)` 静默退化为逗号表达式；libc++ 下清理“记录类型但从未使用”的死变量。

## 6. 破坏性变更与迁移

| 变更 | 影响 | 迁移 |
|---|---|---|
| 模型文件 **v7** | v7 之前写出的 `.nnmodel` / `.nnckpt` 仍可读；新文件不能用旧版本库打开 | 升级到 v1.8.0+；部署用 `.nnmodel`、续训用 `.nnckpt` |
| 删除 NNQT / `--export-deploy` | 旧部署文件与导出命令不再支持 | 改用 `.nnmodel`（三值层自动写打包形态） |
| 删除 `supports_*` 能力谓词 | 直接调用这些基类方法的自定义后端/层编译失败 | 改查 `describe()` 的 `EngineInfo`；后端内部用 `backend_.has_*_pipeline()` |
| 删除 `Layer::sub_layers()` | 外部枚举层树的代码编译失败 | 参数协议改用受保护的 `param_children()`；结构枚举请用模型/层自身 API |
| `--t1_58` 三值预设 | 新增参数，不影响默认 f32 路径 | 需要三值时显式 `--t1_58`；RAPT / ViT 不支持 |
