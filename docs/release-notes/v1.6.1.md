> **发布范围**：`v1.6.0`（`d2dab52`，2026-10-02）→ `v1.6.1`（`384c58b`，2026-10-04）。

## 0. 亮点速览（TL;DR）

| 方向 | 变化 | 收益 |

| f16 正确性 | GPU 写回 `OpFConvert` 的截断改为 **RNE 预舍入** | weight decay 不再因写回舍入方向产生系统性偏差；新增 `f16_writeback_probe` 回归 |

## 1. BatchNorm（roadmap P0-3）

- `compute_layer_mlp.hpp` 新增 `BatchNorm` 层：训练/推理双态、running mean/var 的 EMA 更新、`extra_state` 序列化；`forward_recompute` 路径抑制 EMA 二次更新。
- `make_norm_layer` 增加真实 `batchnorm` 分支（不再静默降级）；CNN / ViT 的 `NormPlace` 可选用 BatchNorm，并设为对应架构默认。
- `scan_exprs` 模型 pass 补齐推理态前向 + 反向覆盖，GPU 闭合世界不再漏结构（库内结构 84 → 91）。
- 新门禁 `batchnorm_test` 与 `batchnorm_test_gpu`（ctest 21 → 23）。

## 2. 作为库消费：`neuralnet::nn`

- 新增门面目标 `neuralnet::nn`：消费方 `add_subdirectory` 后链接该目标即可；嵌入时 `NN_BUILD_APPS` 默认 OFF。
- 接口传递项：C++26、线程库、`NN_HAS_VULKAN`、SPIR-V 嵌入头目录、Vulkan 链接、shader 生成顺序；`Vulkan::Vulkan` 不再需要（也不应）由消费方直接引用。
- 库头所需的 Clang / MSVC 接口选项（`-Wno-pass-failed`、`-fexperimental-library`、`/utf-8`）随门面传递，消费方开 `-Werror` 不再挂在 `#pragma clang loop` 上。
- 样例位于 `examples/downstream/`，指南见 [`../usage/05-consume-as-library.md`](../usage/05-consume-as-library.md)。

## 3. f16 weight decay 写回修复

- **根因**：GPU 写回路径的 `OpFConvert` 对 f16 结果做截断而非最近偶数舍入（RNE），weight decay 的微小负增量在长期累积下产生方向性偏差。
- **修法**：写回前按 RNE 预舍入，再进入 `OpFConvert`；数值语义与 CPU 路径一致。
- **回归**：`f16_writeback_probe` 断言 in-place f16 写回后参数确实移动，并覆盖 8 步 Adam 的参数轨迹；研究归档见 `research/f16_weight_decay/`。

## 4. 旗舰训练前置选项

- `text_train` 新增：
  - `--beta1` / `--beta2`：Adam/AdamW 一阶/二阶动量衰减（LLM 预训练常用 `beta2=0.95`）；
  - `--max-steps`：按本进程步数停止并保存，可与 `--resume` 组合分段跑；
  - `--loss-scope assistant`：仅 `<|assistant|>…<|end_of_assistant|>` 段参与 loss（对话 SFT）。
- 新增 `scripts/download_code_dataset.py` / `scripts/download_math_dataset.py`，把“旗舰开训”的语料准备纳入仓库脚本。
- GUI 与 `bench/gui_cli_audit.py` 同步新增参数面，GUI ↔ CLI 无偏差。

## 5. 构建与测试

- 修 `NN_EXPR_SCAN` 下 `fused_registry` 的 depfile 依赖环（守卫改为嵌套 `#ifndef`），干净构建与增量构建都不再因生成物顺序失败。
- `fused_generate.hpp` / `scan_exprs.cpp` 同步 BatchNorm 结构登记。
- 验收口径：Release 构建零告警（`-Werror`）；ctest **23/23**；`doc_align_audit` / `doc_inventory` / `gui_cli_audit` 全部可行动项为 0。

## 6. 兼容性说明

- **新增**：`BatchNorm` 层、`neuralnet::nn` 门面、`--beta1` / `--beta2` / `--max-steps` / `--loss-scope`。
- **无删除**：既有 Layer / Tensor / 引擎接口不变；`NormPlace` 的既有取值语义保留。
- **行为变化**：请求 `batchnorm` 时现在得到真实层（此前可能静默回落到其他归一化）；依赖“回落”行为的自定义配置需显式改用目标归一化类型。
