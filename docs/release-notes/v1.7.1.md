# neuralnet.cpp v1.7.1 Release Notes

> **发布范围**：`v1.7.0`（`f20532b`，2026-10-05）→ `v1.7.1`（`cf430d0`，2026-10-05）。
> **主题**：**`dataset_gen` 编码进度条**——把 `encode_docs_parallel` 的可选进度报告抽成共享构件。
> **兼容性**：**无破坏性变更**；`encode_docs_parallel` 只增加带默认值的可选参数，既有调用零改动、输出逐字节不变。ctest 保持 **27/27**。

## 0. 亮点速览（TL;DR）

| 方向 | 变化 | 收益 |
|---|---|---|
| 进度反馈 | 进度条构件从 `Tokenizer` 的 protected 静态函数下沉为 `nn::detail::render_progress_bar` / `finish_progress_bar` | `encode_docs_parallel` 这类 namespace 级自由函数也能复用；Tokenizer 原有调用点改薄委托、行为不变 |
| 并行编码 | `encode_docs_parallel` 新增 `show_progress` / `label`（默认关） | `dataset_gen` 在训练集/测试集编码时各显示一条进度条；默认路径零额外开销 |
| 并发安全 | 原子完成计数 + 锁内按 **1% 节流**渲染 | 多线程完成时不会撕裂 `\r` 行，也不会因每个 doc 刷屏拖慢编码 |
| 数据 | 并行分块与保序归位逻辑未动 | 输出与旧路径**逐字节一致**（`dataset_test` 锁定） |

## 1. 改动细节

- `include/neuralnet.cpp/domain_tokenizer_base.hpp`：
  - 新增 `nn::detail::render_progress_bar(label, cur, total, tail)` 与 `finish_progress_bar(label)`；
  - `Tokenizer::render_progress_` / `finish_progress_` 改为薄委托，tokenizer 训练调用点零改动；
  - `encode_docs_parallel(tokenizer, docs, show_progress = false, label = "Tokenize")`：顺序与并行两路逐 doc `tick()`，完成数用 `std::atomic` 累加，渲染在 `std::mutex` 内按 1% 档位节流；`show_progress=false` 时不做任何渲染。
- `src/dataset_gen.cpp`：训练集/测试集各开一条进度条（`Tokenize 训练集` / `Tokenize 测试集`），删除原来的单行 `Tokenize: N docs ...` 提示。
- 文档同步：`AGENTS.md` §12、`docs/history/history.md` 记录演进与本条验收。
